# SDLC Path: Brownfield Adoption

## Repository
`oh-my-antigravity` — standalone node/TypeScript CLI tool and Gemini/Antigravity
CLI extension (depth 0). Published to npm as `@r3dlex/oh-my-antigravity`.

## Path chosen
**Brownfield adoption** — the repo already has a partial scaffold (`.ai/matrix.json`,
`.ai/drift/`, `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `docs/`, `docs/adr/ADR-0001`,
`prek.toml`, `.rules.ts`) generated by an earlier `ai-sdlc-init` run. The v3 upgrade
adds the missing governance layers additively without modifying or deleting existing
content.

## Rationale
- Existing `.ai/matrix.json` already declares `topology_type: standalone`,
  `current_depth: 0`, `sync_strategy: physical-copy` — correct for this repo.
- CI (GitHub Actions: `ci.yml`, `ci-prek.yml`, `release.yml`, `auto-merge.yml`) is
  already configured; no hosted branch-policy mutations are performed
  (`protected main`, PR-only delivery, release-please automation).
- `prek.toml` is present and runs the `validate-rules` archgate hook in CI.
- The repo is not a skills catalog — the skill-modernization branch is inapplicable.
- Cascade is inapplicable (standalone topology has no managed child repos).

## Key decisions
| Decision | Choice | Reason |
| --- | --- | --- |
| Topology | standalone, depth 0 | Single-repo node CLI tool + Gemini extension; no umbrella. |
| Sync strategy | physical-copy | Canonical per `modules/sync.md`; symlinks/submodules rejected. |
| Tracker | GitHub Issues (hosted) | `r3dlex/oh-my-antigravity` is on GitHub; PR-only delivery on protected `main`. |
| Cascade | no-op | Standalone topology; no managed child repos. |
| Skill catalog | excluded | This repo is a node CLI tool, not a skill catalog. |
| Example evalsets | not shipped | No shippable AI surface requiring graded evaluation at upgrade time. |
| ADR location | `docs/architecture/adr/` | New v3 ADRs live here; legacy `docs/adr/ADR-0001` preserved unchanged (no numeric collision — new ADRs use 0003–0005). |
| GEMINI.md | content-bearing (documented exception) | It is the Gemini/Antigravity extension `contextFileName` (see `gemini-extension.json`) and a published product surface; AGENTS.md remains the cross-tool single source, CLAUDE.md is the thin pointer (ADR-0004). |
